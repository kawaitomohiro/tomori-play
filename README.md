# トモリの火が消えた夜（学習発表会の劇）

人数（20〜140人）に合わせて配役と台本が変わり、縦書きのWord（.docx）で出せる、学習発表会の劇のサイトです。

- サイト：https://kawaitomohiro.github.io/tomori-play/
- 作：川合智宏

## 使うときの約束
- 学校での上演は無料です。連絡はいりません。
- 台本は、子どもの実態や人数に合わせて自由に直してかまいません。
- 台本・BGM・背景・イラストを、そのまま、または直したものを、販売したり、ほかのサイトで配ったりすることはできません。
- 上演の録画を動画サイトなどで公開するときは、合唱曲の部分を外すか、各校で著作権の手続きをしてください。BGM・背景の絵が入ったままの公開はかまいません。
- 劇中の合唱曲（例：「大切なもの」作詞・作曲 山崎朋子）の歌詞・伴奏は入っていません。各校で用意してください。

Word出力には docx（MIT License・js/vendor/docx_LICENSE.txt）を使っています。
